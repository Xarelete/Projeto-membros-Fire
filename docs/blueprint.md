# **App Name**: LearnHub

## Core Features:

- Visual Banner: Display a visual banner at the top of the member area to highlight important course information or promotions.
- Course Listing & Access Control: Showcase purchased courses with accessible content, and visually block non-purchased courses, providing a direct checkout link.
- Course Panel Design: Implement a dual-panel layout with course modules and lessons on the left and a prominent video player with a lesson list on the right.
- Lesson Description & Resources: Integrate an interface beneath the video player, providing detailed lesson descriptions and links to supplementary materials like WhatsApp groups.
- Progress Tracking System: Enable users to mark lessons as complete, tracking their progress through each course. Save locally on the browser, instead of to the cloud.
- Responsive Interface: Implement a responsive design that supports both mobile and desktop viewing, optimizing the user experience across devices.
- Dark Mode Option: Allow users to switch between light and dark modes for a comfortable viewing experience in different lighting conditions.

## Style Guidelines:

- Primary color: Use a vibrant blue (#29ABE2) to convey trust and professionalism.
- Background color: Light gray (#F5F5F5) for a clean, modern look.
- Accent color: A bright, analogous purple (#7B68EE) for highlights and calls to action. 
- Body font: 'PT Sans', sans-serif, for clear and accessible text. 
- Headline font: 'Space Grotesk', sans-serif, providing a modern and tech-forward aesthetic.
- Utilize modern, minimalist icons to represent different course categories and functionalities. 
- Incorporate subtle transition animations between sections to enhance user experience and provide a fluid feel.
